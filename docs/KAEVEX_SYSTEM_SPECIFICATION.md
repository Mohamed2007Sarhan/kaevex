# وثيقة المواصفات الفنية الشاملة لمنصة كايڤكس الأمنية (Kaevex Cyber Defense Platform)
**الإصدار:** v1.0.0 Enterprise SOC & Endpoint Defense  
**الترخيص:** Kaevex Cyber Systems - All Rights Reserved  
**تاريخ التوثيق:** سبتمبر 2026

## مقدمة عامة عن المنصة
منصة **Kaevex** هي منظومة أمن سيبراني ودفاع سيبراني متكاملة (Unified Endpoint Detection & Response + SOC Platform) مصممة خصيصاً لأنظمة تشغيل Windows (10، 11، Windows Server). المنظومة مبنية بالكامل بلغة **Pure C (C11)** وواجهات برمجة تطبيقات نظام ويندوز الأصلية (**Win32 / Native APIs**) دون أي اعتماديات خارجية أو أطر عمل بطيئة (Zero External Runtimes - لا بايثون، لا دوت نت، لا جافا).

تجمع المنصة بين قوة وسرعة الدفاع اللحظي، ومراقبة الشبكة وحزم البيانات، واكتشاف الثغرات وترقيعها ذاتياً، والعزل داخل بيئات آمنة، مع تكامل استثنائي لفرق عمليات أمنية ذكية متعددة الأدوار (Autonomous Multi-Agent AI Taskforce).

## 1. المميزات التي تم إنجازها واكتمالها بالفعل (Completed Features)

### أ. الهندسة المعمارية للنظام والوحدات التنفيذية
1. **خفة استثنائية وأداء فائق (Sub-Millisecond Performance):** استهلاك ذاكرة RAM ضئيل (أقل من 25 ميجابايت للواجهة وكافة المحركات)، وسرعة استجابة فورية للأحداث الأمنية.
2. **الوحدات التنفيذية الأربع المتكاملة:**
   - **`Kaevex-GUI.exe`:** واجهة رسومية برمجية بالكامل (Dark Cybernetic Theme) بنظام GDI المزدوج (Double-buffered) تمنع الوميض وتدعم 15 تبويباً عملياتياً متقدماً.
   - **`kaevex-cli.exe`:** طرفية تحكم سريعة لإدارة النظام، إجراء الفحوصات الهاشية، تدقيق جدار الحماية، واختبار حمولات الـ WAF مباشرة من سطر الأوامر.
   - **`kaevex-tray.exe`:** برنامج صينية النظام (System Tray) يعمل في الخلفية بمستوى صامت، مع قائمة سريعة للتحكم بالإيقاف المؤقت أو إغلاق الطوارئ وإشعارات فورية.
   - **`kaevex-engine.exe`:** محرك دفاعي مستمر يعمل كخدمة بدون واجهة لضمان استمرارية الحماية.
3. **التثبيت والإعداد الأولي الذكي (Custom Onboarding & Setup):**
   - معالج التخصيص التفاعلي يسأل المستخدم عند أول تشغيل عن طبيعة استخدامه (خادم ويب، جهاز ألعاب، بيئة تطوير، أو محطة عمل عادية)، ويقوم بتكييف سلوك المحركات وجدار الحماية بناءً على اختياره.

### ب. محركات الدفاع الأساسية الثمانية (8 Core Defense Engines)
1. **محرك مضاد الفيروسات والبرمجيات الخبيثة (Antivirus Core Engine):**
   - استخراج وتوليد بصمات التجزئة التشفيرية المزدوجة (SHA-256 و MD5) عبر مكتبة `CryptoAPI`.
   - مطابقة لحظية مع قواعد بيانات التواقيع الهاشية للبرمجيات الخبيثة المعروفة.
   - تحليل معمق لترويسات الملفات التنفيذية (PE Headers) وكشف أقسام الحزم والتشفير المشبوهة (UPX, Themida, Aspack, etc.).
   - حساب الانتروبيا الرياضية (Shannon Entropy) لكشف الملفات المشفرة أو المحقونة برمجياً.
   - كشف التمويه في الامتدادات (Extension Mismatch) مثل البرمجيات التنفيذية المتخفية بصيغة صور أو مستندات.
2. **محرك مراقبة وتحليل الشبكة (NetGuard Network Engine):**
   - جرد فوري لمآخذ التوصيل الحية (Active TCP/UDP Sockets) وتحديد هوية ومسار العملية المرتبطة بكل اتصال.
   - كشف الاتصالات المشبوهة مع خوادم القيادة والتحكم (C2 Beacon Detection).
   - بالوعة خوادم النطاقات (DNS Sinkhole): حظر وتوجيه النطاقات الخبيثة فوراً إلى العنوان `0.0.0.0`.
   - فحص المنافذ المفتوحة وقطع أو حظر أي اتصال مريب بضغطة زر واحدة.
3. **جدار حماية تطبيقات الويب وحزم البيانات (WebGuard WAF):**
   - فحص وتدقيق الحمولات (Payload Inspection) عبر 18 تصنيفاً هجومياً رئيسياً (SQL Injection, XSS, RCE, LFI/RFI, Log4Shell, Path Traversal, SSRF, Command Injection).
   - نظام تقييم مخاطر متدرج (Risk Scoring System) مع تصنيف خطورة الحادث وتحديد معرّف MITRE ATT&CK و CWE لكل هجوم تم اعتراضه.
4. **درع مكافحة برمجيات الفدية (RansomShield):**
   - نشر أفخاخ رقمية غير مرئية للمستخدم (Canary Decoy Files: DOCX, XLSX, PDF) في مسارات حساسة.
   - مراقبة لحظية لنظام الملفات عبر خيط `ReadDirectoryChangesW` لاكتشاف محاولات التعديل أو التشفير الجماعي السريع.
   - أخذ لقطات فورية وتلقائية للنسخ الاحتياطي عبر خدمة ويندوز الأصلية (VSS - Volume Shadow Copy) لاسترجاع البيانات فور حدوث هجوم.
5. **جدار الحماية التكيفي (Adaptive Firewall Controller):**
   - تحكم كامل في جدار حماية ويندوز وقواعد التصفية (Windows Filtering Platform & Netsh).
   - زر إغلاق الطوارئ اللحظي (Emergency Lockdown): عزل الجهاز بالكامل عن أي اتصال شبكي خارجي مع الحفاظ على الشبكة المحلية أو العكس في أجزاء من الثانية.
   - إنشاء وإدارة قواعد المنافذ المخصصة وتطبيق سياسات الأمان القياسية (Security Baseline Enforcement).
6. **صندوق العزل الآمن الذكي خماسي الطبقات (SmartSandbox):**
   - عزل التطبيقات والملفات المشبوهة داخل حاوية نظام معزولة بتقنية Microsoft AppContainer الأصلية.
   - تقييد كامل للحقوق والامتيازات (Restricted Security Tokens & Job Objects) لضبط استهلاك المعالج والذاكرة.
   - بطاقات سياسات مرئية توضح حالة منع الوصول للشبكة، منع الكتابة على القرص، منع تشغيل العمليات الفرعية، منع الوصول لسجل النظام، وعزل الحافظة (Clipboard).
7. **مركز استكشاف البرمجيات والربط (App Discovery Hub):**
   - فحص آلي عبر 9 مصادر في النظام لاكتشاف وتصنيف البرمجيات المنصبة والخدمات الحية.
   - التعرف التلقائي على المكدسات التطويرية وقواعد البيانات وخوادم الويب (Apache, Nginx, MySQL, Node, Python, Docker).
   - توليد وتعيين مفاتيح ربط وتكامل مشفرة ومقيدة بالـ MachineGuid لتوثيق الاتصال بين التطبيقات.
   - رسم بياني للعلاقات التبادلية بين التطبيقات المنصبة والشبكة.
8. **وكيل كشف الثغرات والترقيع الذاتي (Patch & CVE Agent):**
   - جرد شامل لإصدارات البرمجيات وحزم النظام ومطابقتها الفورية مع قاعدة بيانات ثغرات مدمجة لعام 2024-2026.
   - مراقب حي ودائم لسجل النظام (Registry Watcher) لاكتشاف أي برامج جديدة يتم تنصيبها بالخلفية فوراً.
   - توفير خيار المعالجة التلقائية المدعومة بالذكاء الاصطناعي (1-Click AI Fix) أو عزل البرمجيات المعطوبة فوراً.

### ج. مراكز الذكاء الاصطناعي والفرق المتخصصة (AI Operations)
1. **مركز الفرق المتعددة (Full Team AI Center):**
   - **الفريق الأحمر (Red Team):** تقييم الهجمات الاستباقية، محاكاة الاختراق، وكشف مسارات التسلل في المنظومة.
   - **الفريق الأزرق (Blue Team):** تحليل الحوادث الدفاعية اللحظية، ضبط قواعد الحظر، واستجابة السوك (SOC Triage).
   - **الفريق البنفسجي (Purple Team):** سد الفجوات بين الهجوم والدفاع، ومطابقة التهديدات مع مصفوفة MITRE ATT&CK.
   - **الفريق الأصفر (Yellow Team):** تدقيق الكود المصدري، فحص إعدادات التطبيقات وأمان واجهات الـ API.
   - **الفريق الأخضر (Green Team):** تدقيق الامتثال للسياسات والمعايير الأمنية (ISO 27001, NIST CSF, CIS Benchmarks).
2. **محرك الاستجابة الهجين المقاوم للانقطاع:**
   - استجابة فائقة السرعة مدعومة بسحابة Groq فائقة السرعة مع نموذج LLaMA-3.3-70B.
   - محرك استجابة محلي ذكي (On-Device SOC Intelligence Engine) مدمج بالكامل، يحلل نصوص الأوامر ويوفر إجابات استخباراتية فورية في حال انقطاع الإنترنت أو نفاد الحصة دون أي تأخير.
3. **محلل السوك التفاعلي ودعم النطق الصوتي (AI SOC Analyst & Voice TTS):**
   - شاشة محادثة لتحليل الشكوك وتقديم نصائح أمنية خطوة بخطوة، مع إمكانية تحويل النص إلى صوت مسموع عبر واجهة ويندوز الصوتية (SAPI).

### د. المميزات الميدانية الإضافية
1. **وضع الألعاب المتقدم ومكافحة برامج الغش (Hardened Gaming & Anti-Cheat Mode):**
   - كشف تلقائي فوري لأشهر الألعاب التنافسية (CS2, Valorant, Apex Legends, GTA V, Dota 2).
   - توافق بنسبة 100% مع برامج مكافحة الغش النواتية (Vanguard, Easy Anti-Cheat, BattlEye) دون التسبب بأي حظر أو إيقاف.
   - تحسين أداء المعالج والذاكرة للألعاب وخفض أولوية الفحص في الخلفية لرفع معدل الإطارات (FPS Boost).
2. **شبكة السوك العنقودية الموزعة (SOC Cluster Mesh):**
   - مسح تلقائي لأجهزة الشبكة الفرعية المحلية (/24).
   - ربط وتشفير بين أجهزة المنظومة عبر رموز إقران آمنة ومراقبة زمن الاستجابة (Ping Latency).
3. **السجل الجنائي المشفر غير القابل للتلاعب (Forensics Audit Trail):**
   - تسجيل إلحاقي حصري (Append-only) لكل حدث وتنبيه، مع إمكانية البحث الفوري والتصدير لصيغ التقارير المعتمدة.

## 2. المميزات الجاري العمل عليها وصقلها حالياً (In-Progress Features)

هذه المميزات تم تصميم بنيتها التحتية، وتخضع حالياً للربط والإنهاء الدقيق في الكود:

1. **الرسم البياني الحي المتدفق للداشبورد (Dynamic Live Rolling Wave Chart):**
   - تحويل المخطط البياني في التبويب الرئيسي (Support Dashboard) من خطوط إحصائية ثابتة إلى منحنى موجي حي يتدفق بانسيابية كل 1500 ملي ثانية.
   - تصميم بصري حديث بتباين نيون أزرق كهربائي (Neon Cyan) للبيانات القادمة، ونيون برتقالي عنبري (Hot Amber) للأحداث المصفاة والمهددة، مع تظليل تدريجي لمنطقة أسفل المنحنى ونقاط قمم متوهجة (Glowing Nodes).
   - ربط الحركة بمعدل الحزم الحقيقي، عدد الاتصالات المفتوحة، وتنبيهات محرك الـ WAF وجدار الحماية.
2. **الفحص الشامل التلقائي للملفات عند بدء التشغيل (Startup Auto-Scan Worker):**
   - إطلاق خيط معالجة بالخلفية فور فتح الواجهة لفحص ملفات النظام التنفيذية الحساسة، مجلدات بدء التشغيل التلقائي (Startup Folders & Run Keys)، مجلدات Temp، AppData، Downloads، و System32.
   - فحص آلاف الملفات بهدوء تام دون أي تجميد للواجهة الرسومية، مع إشعار المستخدم فور اكتمال الفحص بملخص النتائج.
3. **قاعدة بيانات التهديدات المستمرة مع زر التحقق والأمان (Persistent Threat DB & Safe/Whitelist Action):**
   - إضافة قسم مخصص في تبويب الـ Antivirus لعرض الملفات التي تم اكتشافها كتهديدات، مع إظهار مسار الملف، نوع الخطر، ونسبة الخطورة.
   - زر التحقق ("Mark Safe / Whitelist"): يتيح للمسؤول وسم أي ملف كملف موثوق (False Positive Override)، وتخزين هاش هذا الملف في قاعدة البيانات لتجاوزه فوراً في أي فحص قادم.
   - زر العزل الفوري ("Quarantine"): عزل الملف الخبيث في بيئة مشفرة ومغلقة لمنع تنفيذه.
   - قاعدة بيانات دائمة ومستمرة تحفظ في ملف `kaevex_threats_db.json` مع نسخة احتياطية في Registry تضمن بقاء القرارات والملفات المكتشفة حتى بعد إعادة تشغيل الجهاز.
4. **تطوير واجهة المحادثة التفاعلية الذكية (AI Chat Bubbles & Text Encoding Polish):**
   - تحويل عرض نصوص المحادثة مع الفرق ومحلل السوك إلى فقاعات رسائل حديثة ومريحة للعين (فقاعات بلون مرجاني للمستخدم في اليمين، وفقاعات زرقاء/سماوية للمحلل في اليسار).
   - إزالة أي أحرف أو رموز مشوهة ناتجة عن اختلافات ترميز UTF-8 عبر استخدام رسم المتجهات النقي في واجهة الـ GDI (مثل رسم الدوائر عبر دوال الرسوميات المباشرة).
5. **إعادة ضبط وتنظيم App Hub:**
   - إزالة أزرار التحكم غير المتناسقة (مثل أزرار تشغيل وإيقاف XAMPP) والتركيز على إدارة الهوية، فحص الاعتماديات، وتوليد الرموز الأمنية المشفرة.

## 3. المميزات المستقبلية والمخطط تنفيذها (Planned / Roadmap Features)

المرحلة القادمة ستنقل Kaevex إلى مستوى منصات الدفاع القومية والمؤسسية الكبرى:

1. **برنامج تشغيل نواتي بمستوى الحماية القصوى (Kernel-Level WFP & Minifilter Driver):**
   - تطوير مشغل نواتي (Ring-0 Kernel Driver) يعمل بتوقيع رسمي لفلترة الحزم على أدنى مستوى لنظام التشغيل ومنع أي برمجيات خبيثة من تجاوز قواعد جدار الحماية (Firewall Bypass Prevention).
   - مراقبة عمليات القراءة والكتابة للقرص لحظياً عبر Minifilter لمنع محاولات تعديل الـ MBR أو تشفير الملفات في أول ميلي ثانية.
2. **الربط مع شبكات استخبارات التهديدات العالمية (Global Threat Intelligence Federation):**
   - دعم بروتوكولات STIX 2.1 و TAXII لمزامنة خلاصات التهديدات (Threat Feeds) لحظياً مع مراكز أمنية عالمية.
   - تكامل مدمج مع منصات التحليل السحابي المفتوحة ومكتبات VirusTotal v3 API و AbuseIPDB للتحقق المباشر من سمعة الهاشات وعناوين الـ IP.
3. **محرك ذكاء اصطناعي محلي معزول بالكامل (Offline On-Premises LLM Runtime):**
   - دمج محرك استدلال كمومي محلي بالكامل (باستخدام مكتبات GGUF / llama.cpp المكتوبة بلغة C) لتشغيل نماذج ذكاء اصطناعي متخصصة في الأمن السيبراني بحجم 3B إلى 8B محلياً على كرت الشاشة أو المعالج.
   - يتيح هذا العمل في البيئات المغلقة تماماً والمعزولة عن الإنترنت (Air-Gapped Environments) كالمطارات والمستشفيات والمنشآت العسكرية بدون إرسال بايت واحد إلى السحابة.
4. **العزل الافتراضي المتقدم عبر المايكرو-في إم (MicroVM / Hardware Hypervisor Isolation):**
   - تطوير صندوق العزل لاستخدام تكنولوجيا الحاويات الخفيفة المدعومة بالعتاد (Hyper-V Containers & Windows Sandbox API) لاختبار الملفات شديدة الخطورة وعينات الـ APT مع إمكانية إرجاع بيئة النظام للصفر فور انتهاء التجربة.
5. **تطبيق مراقبة محمول ولوحة سحابية مشفرة (Mobile Companion & Cloud Console):**
   - تطبيق خفيف للهواتف الذكية (iOS / Android) يتلقى تنبيهات الحوادث الحرجة عبر Push Notifications مشفرة (End-to-End Encrypted).
   - إمكانية تفعيل إغلاق الطوارئ الشامل أو عزل أي خادم من الهاتف الذكي عند حدوث تسلل في أوقات خارج العمل.
6. **محرك الأتمتة والاستجابة الذاتية للحوادث (SOAR Playbooks Automation):**
   - مصمم مسارات أمنية مرئي يتيح لمدير النظام كتابة قواعد تفاعلية مثل:
     *(إذا رصد الـ WAF أكثر من 5 محاولات RCE من نفس الـ IP في دقيقة واحدة -> احظر الـ IP في جدار الحماية فوراً -> اعزل العملية المستهدفة داخل Sandbox -> أرسل تقريراً شاملاً لفريق السوك عبر الويب هوك)*.

## خلاصة
منصة **Kaevex** ليست مجرد برنامج حماية تقليدي، بل هي بيئة أمن سيبراني دفاعية مستقلة، مصممة للمستقبل، تجمع بين الأداء الصاروخي للغة السي الأصلية، والذكاء التكتيكي للذكاء الاصطناعي، وعمق السيطرة على موارد وإمكانيات نظام ويندوز.
